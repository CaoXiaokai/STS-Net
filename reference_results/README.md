# 绘图参考结果

- `subject_results.csv`：正式噪声批次的63条逐人结果。
- `condition_summary.csv`：同批7个条件的原始汇总。
- `eog_snr_accuracy_data.csv`：用户最终核实并提供的七方法服务器实验均值，用于论文七条曲线。

这些CSV用于重现论文噪声图和表格，不用于初始化模型，也不作为新训练任务的完成记录。保留原CSV中的额外字段便于核对；绘图仅使用论文需要的准确率，表4仅使用平均准确率和平均Kappa。

已核对前两份CSV与原正式批次审计结果一致。第三份CSV不包含baseline训练实现或服务器逐人日志；不能据此声称已在本机复现六种对比方法。
